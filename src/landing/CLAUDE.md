# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Dog Appa - лендинг для мобильного приложения для владельцев собак. Статический сайт на чистом HTML/CSS/JS без сборщиков и фреймворков.

## Architecture

- **index.html** - основная страница с hero-секцией, возможностями приложения, формой подписки и модальным окном политики конфиденциальности
- **styles.css** - стили с мобильной адаптацией (breakpoint 992px)
- **script.js** - логика форм, навигации, модального окна, анимаций через IntersectionObserver

## Key Features

- Формы подписки отправляют данные в Google Forms (no-cors)
- Валидация контактов: email, Telegram (@username), телефон
- Smooth scroll навигация по якорям
- Success alert с анимацией появления/скрытия

## Development

Открыть index.html в браузере. Сборка не требуется.

## Language

Весь контент на русском языке.

## Правила работы со стилями

**ВАЖНО: Перед изменением CSS обязательно:**

1. Проанализировать ВСЕ медиа-запросы где может быть переопределение стилей (768px, 480px, 1024px и т.д.)
2. Проверить каскад - какие базовые стили наследуются и переопределяются
3. Сравнить оригинальные inline-стили со всеми существующими правилами в CSS
4. Только после полного анализа вносить изменения
5. Не спешить - лучше один раз правильно, чем переделывать
